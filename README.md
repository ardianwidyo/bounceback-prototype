# BounceBack: clickable prototype

**Live demo:** https://ardianwidyo.github.io/bounceback-prototype/

A clickable demo of BounceBack, a blame-free companion that helps people start, keep and come back to healthy habits. Three fictional patients with Synthea-format FHIR records are run day by day through the real BounceBack engine, showing:

1. **Onboarding:** goals and safety exclusions suggested from the synthetic health record
2. **Plan generation:** 2–3 small actions chosen by auditable rules, each with a "Why this?" card
3. **Lapse detection:** a daily lapse-risk score with plain-language, blame-free reasons
4. **Recovery:** a lighter plan for the barrier the person picks, with progress kept intact
5. **Step back up:** an optional return to the earlier pace after 5 check-ins

All people and records are synthetic. Nothing here is medical advice.

This repository holds only the built page (`index.html`, one self-contained file). The source and engine live in a separate private repository; the page is generated by `data/synthetic/build_prototype.py`.
